# ElevateRoute

An AI-powered web application that generates personalized career roadmaps for students based on their skills and goals.

## Features
- User authentication (login/signup)
- Profile setup and onboarding
- AI-generated career roadmaps
- Milestone tracking
- Progress dashboard

## Tech Stack
- Lovable
- Supabase (Database & Authentication)
- GitHub
- REST APIs

## Description
ElevateRoute helps users plan their careers step-by-step by analyzing their inputs and generating structured learning paths with progress tracking.
